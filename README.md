# ttpf-kit

Command-line toolkit for `.ttpf` texture containers (RDS5 header, chunk table, ETPF descriptors).

    python -m ttpf_kit info file.ttpf
    python -m ttpf_kit verify file.ttpf
    python -m ttpf_kit extract file.ttpf 3 out.bin
    python -m ttpf_kit replace file.ttpf 3 new.bin out.ttpf [--zlib]
    python -m ttpf_kit diff old.ttpf new.ttpf change.json
    python -m ttpf_kit apply old.ttpf change.json new.ttpf

Pure Python 3, no dependencies, runs on Linux and Windows. `python run_tests.py` runs the tests.

## What it covers

Chunk table and descriptor parsing and writing. Chunk replacement keeps every other byte, including bits the notes don't explain, and rewrites only the chunk end offsets. Patches record the base hash, per-chunk hashes and the result hash, so applying to the wrong file fails.

## What it does not cover

BCPack chunks (codecs 1 to 7 on a chunk) are treated as opaque bytes. They can be swapped whole, not decoded or re-encoded. Mip rules, ETPF field C and some descriptor fields are not understood, so they are preserved, never regenerated.

## Sources

Layout follows two MIT-licensed community sources that disagree in places (see ttpf-spec): the notes in SentinelInteractive/0x52504639 and the source of paryzius/ttpf-viewer. Fields they disagree on are preserved as raw words, not interpreted. Tests use synthetic files generated by `ttpf_kit/fixtures.py`. No game files are included. Tested on synthetic files only; the layout comes from community notes, not an official spec.

Related: [ttpf-spec](https://github.com/BaptistSec/ttpf-spec), the layout as a structured spec.
